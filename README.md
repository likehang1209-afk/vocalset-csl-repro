# VocalSet CSL reproducibility code

The [versioned code and recipes archive](vocalset-csl-repro-20261117-v2.zip)
contains the singer-independent evaluation pipeline, six prior-system
adaptations, fixed split and model configurations, three-schedule analysis,
shared-weight diagnostics, and the exploratory GTSinger paired recipe. See
the README inside the archive for entry points, inputs, and limitations.

- Archive SHA-256:
  `d3c4f7de0f0084e3ffb063da8d8e388c42f92aa81476225cecb93989f5d8d6e4`
- Verified in a fresh extraction: 145 files and 52 unit tests.
- The archive does not contain recordings, model weights, individual
  predictions, the manuscript, or peer review correspondence. Some analysis
  entry points need separately retained non-audio inputs. The tests do not
  constitute a rerun of the reported experiments.
